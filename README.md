# scholarship-eligibility-system
A web-based scholarship eligibility checker using CGPA, attendance, and family incom

## 📌 Project Overview

The **Scholarship Eligibility System** is a simple web-based application designed to determine a student's scholarship eligibility based on three important factors: **CGPA, attendance percentage, and family monthly income**.

The system takes the student's information as input and automatically displays the scholarship result according to predefined eligibility criteria. It helps demonstrate basic programming concepts through a practical and easy-to-use interface.

## 🎯 Project Objectives

- To check student eligibility for scholarships.
- To evaluate CGPA and attendance requirements.
- To determine the scholarship percentage based on family income.
- To practice conditional statements and decision-making logic.
- To develop a simple, interactive web application.

## ✨ Features

- **CGPA Validation:** Accepts CGPA values between 0.0 and 4.0.
- **Attendance Checking:** Evaluates attendance on a scale of 0–100%.
- **Income-Based Assessment:** Checks family monthly income in Pakistani Rupees (PKR).
- **Automatic Results:** Displays eligibility status immediately after submission.
- **Simple Interface:** Easy to use for students and beginners.
- **Instant Feedback:** Shows the reason for ineligibility or the scholarship percentage awarded.



## 🚀 How to Run the Project

1. Download or clone this repository.
2. Locate the `index.html` file.
3. Double-click the file to open it in your web browser.
4. Enter the student's CGPA, attendance percentage, and monthly family income.
5. Click the check button to view the scholarship result.

No additional software installation is required to run the web application locally.
